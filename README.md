# Grid-Pro

Professional Camera2 API camera app for Android 12+ featuring Universal HDR 10-bit video recording, MOV container support , JPEG snapshots during video capture, LUT support and advanced manual controls.

## Features

• Universal HDR 10-bit video capture
• MOV container recording
• JPEG snapshots 
• LUT preview and export support
• Manual focus control
• AF-C and AF-S autofocus modes
• Exposure compensation controls
• Multiple resolutions and frame rates
• Grid overlays
• Advanced controls
• Clean and responsive interface

## Requirements

• Android 12 or later
• Camera2 API compatible device
• HEVC support recommended for HDR recording
